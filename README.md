# Proxy Hub

Proxy Hub — плагин для Telegram, который объединяет сбор, проверку, сортировку, импорт/экспорт и очистку прокси в одном интерфейсе. Плагин предназначен для работы с поддерживаемыми сборками Telegram и помогает автоматизировать управление списком прокси.



## Поддерживаемые сборки
Плагин работает **только** в следующих проектах:

- [AyuGram/AyuGram4A](https://github.com/AyuGram/AyuGram4A)
- [exteraSquad/exteraGram](https://github.com/exteraSquad/exteraGram)

## Что умеет плагин

### 1. Автосбор из Telegram
Плагин собирает прокси автоматически из:
- публичных Telegram-каналов;
- приватных каналов вида `t.me/c/...`;
- чатов;
- топиков/тем;
- каналов, добавленных через контекстное меню внутри чата.

Поддерживаемые форматы источников:
- `@channel`
- `https://t.me/channel`
- `https://t.me/c/1234567890`
- `dialog:-1001234567890`
- `dialog:-1001234567890:5`

### 2. Сбор из веб-источников
Плагин читает прокси из:
- GitHub raw-файлов;
- обычных веб-страниц;
- JSON-списков;
- base64-подписок;
- текстовых списков в любом удобном формате.

Также поддерживаются ссылки вида:
- `tg://proxy?...`
- `tg://socks?...`
- `tg://webproxy?...`

### 3. Автоматический таймер
Есть встроенный таймер автосбора:
- настройка интервала запуска;
- автоматический сбор по расписанию;
- возможность включать/выключать автосбор;
- сохранение статуса последнего запуска.

### 4. Дедупликация и фильтрация
Плагин автоматически:
- удаляет дубликаты;
- игнорирует уже существующие прокси;
- проверяет, что новые ссылки действительно распознались;
- хранит состояние чтения по каждому источнику, чтобы не пересматривать старые сообщения.

### 5. Проверка прокси (ping)
Плагин умеет проверять список прокси двумя способами:
- через нативный Telegram-проверяющий механизм;
- через TCP-проверку доступности порта.

Также есть:
- сортировка по пингу;
- отображение состояния работы;
- удаление нерабочих прокси;
- удаление всех прокси по одному действию.

### 6. Нормализация секретов
Плагин нормализует MTProxy/TLS-секреты, приводя их к корректному hex-виду, что снижает вероятность ошибок при работе с разными форматами секретов.

### 7. Геолокация и метки
Для каждого прокси:
- определяется страна по IP;
- определяется провайдер;
- отображается флаг страны;
- отображается тип прокси: MTProto / SOCKS5.

### 8. Скрытие спонсорского прокси
Плагин умеет скрывать рекламный/спонсорский proxy из списка Telegram, если такая запись присутствует в UI списка прокси.

### 9. Импорт/экспорт
Поддерживаются:
- импорт списка источников из буфера обмена;
- экспорт списка источников в буфер обмена;
- экспорт прокси в Избранное;
- экспорт в текстовый файл при большом объёме данных.

### 10. Белый список чекер
В плагине встроена диагностика белых списков:
- проверка доступности ключевых российских и нейтральных сайтов;
- оценка вероятности блокировок/белых списков;
- анализ сети;
- определение наличия VPN;
- статус подключения и типа сети.

Чекер белых списков был адаптирован на основе проекта:
- @Aleksey-Kon/white-list-test

## Архитектура функционала

### Источники
Плагин хранит:
- Telegram-источники;
- веб-источники;
- состояние чтения (src_state);
- время и результат последнего сбора;
- статус проверки каждого источника.

### Работа с прокси
Плагин хранит и обрабатывает:
- адрес;
- порт;
- secret;
- user/pass;
- тип прокси;
- статус доступности;
- время последней проверки;
- список уже добавленных ключей, чтобы исключать дубликаты.

### UI
Плагин включает:
- карточки вкладок;
- сворачиваемый список источников;
- кастомные кнопки в шапке списка прокси;
- индикаторы статусов;
- цветовую тему и визуальные панели;
- адаптивные UI-компоненты.

## Установка

1. Скопируйте файл `proxy_hub.plugin` в папку плагинов вашей совместимой среды.
2. Активируйте плагин в списке доступных плагинов.
3. Откройте настройки плагина.
4. Добавьте Telegram-источники или веб-ссылки.
5. Запустите сбор вручную или используйте автосбор.

## Пример списка источников

```text
@proxy_feed
https://t.me/proxy_list
https://raw.githubusercontent.com/user/proxies/main/proxies.txt
https://example.com/proxy.json
dialog:-1001234567890:5
```

## Пример прокси ссылок

```text
tg://proxy?server=1.2.3.4&port=443&secret=...
tg://socks?server=1.2.3.4&port=1080&user=user&pass=pass
tg://webproxy?server=1.2.3.4&secret=...
```

## Ограничения и риски

- Работа зависит от совместимости с конкретной сборкой Telegram.
- Сбор из внешних источников зависит от доступности серверов и правил сторонних ресурсов.
- Некоторые прокси могут быть недоступны или временно не работать.
- Белый список чекер является диагностическим инструментом и может давать приблизительные результаты в зависимости от сети и VPN.
